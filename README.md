# AstraClient

AstraClient is a personal Minecraft: Java Edition launcher and Fabric mod.
It installs Fabric and the mod and starts the game, and it shows synced
lyrics for the song playing on the player's own Spotify account.

- Signs in with the player's own Microsoft account (device code flow)
- Only for personal use, not commercial, not sold
- Does not redistribute Minecraft files; they are downloaded from Mojang
- Not affiliated with Mojang or Microsoft
